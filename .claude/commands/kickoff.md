description: Đọc toàn bộ bối cảnh dự án trước khi làm (không code)
---
Bắt đầu phiên. Máy và việc: $ARGUMENTS
Chưa viết code, chưa sửa file. Làm lần lượt:
1. Đọc CLAUDE.md; PLAN.md mục 6, 10, 11; IMPLEMENT.md mục 0, mục 11 (mốc đang mở) và mọi mục mà mốc đó trỏ tới.
2. Không đọc DESIGN.md của getdesign. Giao diện theo DESIGN-HBT.md.
3. Chạy git status, git branch --show-current, git log --oneline -5, git stash list.
4. Báo ngắn dạng bảng: máy (có/không GPU); mốc đang mở, nhánh, việc đã xong/chưa xong; việc phiên này và mục đặc tả liên quan; luật sẽ áp; điểm đặc tả chưa rõ.
5. Chờ tôi duyệt rồi mới làm.
